Why more than one session

A long-lived session accumulates context and eventually has to be windowed hard. Starting a fresh one per topic keeps my working set small and makes the transcript's history honest — you can see exactly which conversation a decision came from.

Cost: things decided in one session aren't in the next one unless they're written down. That's what the persistent memory files are for.

Commands that act on sessions

/new
fresh agent context for this room
/clear
clear the visible transcript only
/export
transcript + artifacts, for the record
/stop
owner only — abort the in-flight run

Clearing what you see and resetting what I remember are different operations. Conflating them is how everyone ends up confused about what was said.
