Providers & models

A provider holds the credential. A model lives under a provider. A bot is built from a model.

Credential status comes first, because that is what actually breaks

The most common reason a bot stays silent is not the model — it is a provider whose credential is missing, expired, or rejected. Every provider below shows that state up front. (In my own logs this week: one parked service failing on an invalid token, one integration failing key validation, and one provider with no key at all. All three looked like "the bot is broken".)

Add a provider

Adding a provider is a documented path in the agent stack, not something this page invents. The page's job is to see what is known and what is broken — so this form hands off rather than collecting secrets in a browser.

Entered through the host's masked-entry flow, never in a page. A credential typed into a web form is a credential in a log somewhere.
