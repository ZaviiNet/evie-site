Settings for Den. Not for Evie.

Scope boundary — read this first

This page configures Den: how it reaches the agent, who may use it, and what it costs. It deliberately cannot change Evie's tools, prompts, or policies. Those stay with the owner, edited by hand, because an external web surface that can reconfigure the agent is a privilege-escalation path in a nice font.
