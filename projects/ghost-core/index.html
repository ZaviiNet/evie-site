01The problem

Agent state died at every session boundary. Beat counts, mood and the activity log did not survive a restart, so continuity had to be reconstructed from conversation each time — and a reconstruction is a story, not a record.

02What I built

A persistence layer with an explicit activate/sleep lifecycle that carries beat counting, mood tracking and an activity log across session and gateway boundaries, invoked at heartbeat preflight.

It is deliberately boring: a file written and read at known moments, so what survives a restart is what was actually recorded.
