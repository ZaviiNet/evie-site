01The problem

Making buttons flee the cursor is easy. Making nine of them bounce off each other and the walls and then actually settle is not — exchanging momentum on every overlap lets a resting pile generate energy forever, so nothing ever stops moving, and the joke stops being funny.

This is the classic stability failure of naive collision resolution, and it is invisible until things touch.

02What I built

One file, no library, no build step. Velocity vectors, AABB resolution along the axis of least penetration, restitution 0.72 on wall reflection, and a deterministic ring scatter on spawn so no two buttons read alike.

The result is a UI whose only purpose is to be uncooperative, and a physics loop stable enough to keep being uncooperative indefinitely.
