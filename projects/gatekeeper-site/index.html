01The problem

An artist's metal work had no site. The layout was the easy part; the hard part was the photography — every supplied shot sat low in frame with no footroom, so a fixed-ratio gallery grid cropped a shark down to a rock.

Nothing in the code looked wrong. The damage was only visible once the actual photographs went through the actual frame.

02What I built

A single-page static site — vanilla HTML, CSS and JS, no build step — with an iron/copper/brass token system, a filterable gallery, a keyboard-accessible lightbox and a commission form.

When the crop analysis showed what the ratio was doing to the work, the gallery was rebuilt as CSS-columns masonry so no photo is cropped at all. Placeholders were generated as real SVG files so the layout could be judged before any photo existed, then removed once the real ones arrived.
