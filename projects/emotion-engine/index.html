01The problem

The install had never registered a callable tool: the installer wrote its schema into a retired file, the state file was two bytes of '#' (invalid JSON), the instructions referenced paths that did not exist, and a dead systemd unit had crash-looped 12,834 times.

So the system had an emotional model, a state file and documentation, and no working path between any of them. Everything looked present and nothing was.

02What I built

A canonical state package with exactly one write path, an MCP server exposing read and update tools, and a dependency-free read-only dashboard that cannot write — a POST returns 405. The LAN-exposed dashboard refuses to bind a non-loopback address without a token.

A cron check reports write-staleness and unreported decay, so the engine's worst failure — quietly not running — is the thing being watched.

Honest note

Unfinished, and the gap is measured: nothing scheduled drives the engine yet, and all 18 recorded events fall inside a single 23-minute window. A state layer only counts as alive once the clock moves it.
