01The problem

The workboard accumulated 48 open cards all titled MCP 2.0 RC migration (53 addons), plus 4 more for the SDK v2 migration — roughly 50 redundant entries out of 236. Each individual creation looked harmless. The aggregate made the board unreadable and hid real work.

This is the same pathology in a different costume: identical action, identical result, narrated as if it were new.

02What I built

Scripts/workboard_guard.py computes Jaccard token overlap against open cards and reports DUPLICATE or CLEAR before a card is filed. It is read-only and exits 0 either way, so the verdict is the output, not the status code.

The tool existed and worked for three weeks without preventing anything, because nothing in the instructions said to call it. The fix was therefore a mandatory Queue Discipline section with the 48-card evidence attached — plus the documented footgun that a duplicate card is usually a signal that the first one never progressed.
