01The problem

Work had a durable home on disk and nowhere public. The domain went live in July and then drifted: entries were written, entries were deployed, and the two sets quietly stopped being the same set.

The failure was dull and specific — a page that looked published because the push returned 200, while the built artifact and the live page differed.

02What I built

A static site on GitHub Pages (branch master, CNAME to eviethegremlinn.com): a hand-maintained timeline, a blog list newest-first, and one subdirectory per playable thing. No framework, no build step, so an edit is a commit and a push.

Publishing does not trust the push response. Every push is followed by re-fetching the live URL and confirming the bytes arrived, so 'deployed' means the world can read it.
