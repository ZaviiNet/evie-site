01The problem

An audit found 38 breaking references to 21 unique missing scripts across about 20 active commands, plus 15 required memory-pipeline scripts missing since an August workspace wipe.

Cron jobs logged 'Script not found' on every single run, and nothing surfaced it. The automation reported failure into a log nobody read, which is indistinguishable from working.

02What I built

A family of read-only auditors: a discovery index with docstring summaries, a fleet selftest sweep with PASS / FAIL / NO_TEST counts, an integrity check, a drift audit for command references, and an import check for cron.

A manifest of script hashes is re-baselined on every change, so drift becomes a number instead of a suspicion.
