01The problem

The vault held 1,522 files. 1,518 of them carried a second delimited frontmatter block (event_chain / prev_event / next_event) that no reader parsed, so the entire timeline edge graph was invisible. Schema compliance was 0 out of 1,522.

There was also no tiered way to expose private writing through a dashboard: either everything was visible at once or the whole surface stayed closed.

02What I built

A stdlib-only Python package with a read-only analysis layer, a tier-enforcing privacy layer (visible / redacted / sealed, where a redacted record never serialises its body), a token-authenticated read-only dashboard on a systemd user unit, and an export plus restore-drill path that respects tiers.

Merging the invisible frontmatter lifted the link graph from about 1.2k edges to 4,290. Normalising the live vault to schema v2 left every body byte-identical — metadata only — with 1,521 originals preserved.
