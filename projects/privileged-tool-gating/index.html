01The problem

An audit of the Discord command handler found exactly 2 owner-gate sites in the source — while memory deletion, download queues, credit-burning generation and script execution all ran ungated. On a shared server, anyone who knew a command name could wipe vault memories or spend money.

The second finding was worse than the first: nobody had asked the question, because there was no map of which tools were dangerous in the first place.

02What I built

Three paired instruments. A static blast-radius map ranks the whole tool surface by consequence (8 CRITICAL / 11 HIGH / 10 MEDIUM / 34 LOW) and can trace which high-blast tools are reachable from an untrusted source. A per-intent gate answers SAFE / MANAGE / APPROVAL for one specific call and fails closed on unknown or destructive intent. A centralised owner gate in the slash handler became the single source of truth for 15 commands, refusing when the owner id is unset or the caller is not the owner.

The coverage question was then re-asked through the blast-radius lens, so 'no ungated privileged command remains' is a measured statement rather than a guess.
